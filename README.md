# IBM-WATSON
IBM Watson – Automated Machine Learning Pipeline

📌 Practical Overview

This practical demonstrates the use of IBM Watson for automated machine learning and pipeline generation. It illustrates how data is processed, algorithms are selected, pipelines are evaluated, and the final pipeline is generated for backtesting.

🎯 Objectives

* Understand automated machine learning using IBM Watson.
* Explore feature transformers and machine learning algorithms.
* Understand automated pipeline selection and generation.
* Observe pipeline evaluation and backtesting.
* Understand the role of training and holdout datasets.

🛠️ Workflow

The practical demonstrates the following steps:

1. Read Dataset: Import the dataset into the environment.
2. Split Holdout Data: Separate data for training and testing.
3. Read Training Data: Load the training dataset.
4. Imputer Selection: Handle missing values in the dataset.
5. Lookback Window Generation: Generate the required lookback window.
6. Pipeline Selection: Select suitable machine learning pipelines.
7. Algorithm Selection: Explore algorithms such as Enabler and ARIMA.
8. Pipeline Evaluation: Evaluate the generated pipelines.
9. Final Pipeline Generation: Generate the selected final pipeline.
10. Backtesting: Test the generated pipelines to assess their performance.
